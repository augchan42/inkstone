Round 1: Style as Suffix

First attempt: describe the scene, then append "Chinese ink painting style". Results were wildly inconsistent.

Muddy, photorealistic, no composition

Stock photography, not ink painting

The model ignores trailing style directives. It responds to the language of the prompt.

05
Core Discovery

Style Is Not a Suffix

The prompt must read like the caption under an ink painting — painterly metaphors woven throughout, not appended at the end.

# Bad — style as suffix "A tree on a hill. Chinese ink painting style." # Good — painterly language embedded in the scene "A gnarled pine leans from a cliff face like a brushstroke frozen mid-sweep, roots gripping stone above a gorge filled with morning mist. Chinese ink painting."
06

Round 2: Same Verse, Different Register

The verse 井之渙 — testing wabi-sabi description vs. embedded painterly language:

"Pale early-spring light, everything wet and glistening. Ink wash with cool blue-green tints."

"Water spills over the stone lip in thin silver threads, tracing dark lines down worn steps like brushstrokes on parchment."

07

The 7 Composition Rules

1
Frame the scene — gorges, gates, tree canopies. Never a subject floating in open space.
2
Force depth — foreground, midground, background. Always.
3
Demand contrast — strong light against darkness, or dark against light.
4
Warm accent — even in monochrome: amber, vermillion, pink, or gold.
5
Favor diagonals — avoid flat horizontal compositions.
6
Discoverable detail — reward the second look with secondary subjects.
7
Painterly scene language — "like ink drops", "pale threads", "like shattered porcelain". End with "Chinese ink painting." but never use photographic language.

bold-action Dynamic diagonals, warm ochre Animals, combat, hunts, storms
cosmic-night Deep blue/black + gold/white Stars, heaven, mythical beasts

Abstract verses (fortune/misfortune) fall back to tone: ominous → atmospheric-night, auspicious → ink-landscape

14

The Breakthrough: Language Is Style

Stop appending style. Write the prompt as if it were the caption under the painting.

An overflowing well sends water spilling in four branching streams across barren hillside, carving shallow channels in the earth. Foreground, the well mouth brims over, water sheeting across worn stone. Midground, the streams diverge eastward, spreading thin over sun-baked ground, nourishing sparse grasses. Beyond, desolate brown hills roll to a hazy horizon, the water lost among them. Amber reflections glint where the shallow streams catch the last daylight. Chinese ink painting.
✓ Frame ✓ Depth ✓ Contrast ✓ Warm accent ✓ Diagonals ✓ Detail ✓ Painterly

16

Content Safety: 52 of 4,096 Failed

Ancient texts contain warfare, predation, suffering. Image APIs reject explicit harm. The solution: depict through atmosphere and aftermath, never the act itself.

Blocked ConceptSafe Alternative
Blood on surfaces"Dark stains like spilled ink"
Fallen bodies"Abandoned armor on bare ground", "an empty seat at a banquet table"
Animal predation"Scattered feathers on snow", "a wolf's shadow crossing moonlit ground"
Dismemberment"A shattered puppet", "a split tree trunk"

The constraint forced better art — absence evokes more dread than depiction.

What Is a Skill?

A SKILL.md file with YAML frontmatter + instructions. No runtime code — pure prompt engineering that encodes domain expertise.

--- name: verse-to-prompt description: Convert classical Chinese verse into image prompts user-invocable: true argument-hint: [paste your verse here] --- # Verse → Image Prompt Given a verse, produce: 1. A style classification with rationale 2. A 50-60 word English prompt ending "Chinese ink painting." 3. A faithful English translation ## The 7 Composition Rules (MANDATORY) ...

A skill carries pre-tested expertise. The agent doesn't rediscover principles — it inherits them.

19

Plugins vs Skills

Plugin = Package

  • ■ A Git repository with a manifest
  • ■ Contains 1+ skills, agents, hooks
  • ■ Installed via /plugin install
  • ■ Versioned, shareable, discoverable
.claude-plugin/ plugin.json # manifest skills/ verse-to-prompt/SKILL.md blakean-scene/SKILL.md ...

Skill = Behavior

  • ■ A single SKILL.md file
  • ■ Defines one specific capability
  • ■ Invoked via /skill-name
  • ■ No code — instructions only
# Usage: /verse-to-prompt 白駒食場，一躍而去。 Style: ink-landscape Prompt: A white colt grazes in a walled courtyard...

Beyond Claude Code

The skill format is spreading. CLAUDE.md files — project-level instructions — are already supported across tools:

▶
Claude Code — full plugin system with SKILL.md, agents, hooks, MCP servers · Anthropic
▶
OpenCode — reads CLAUDE.md for project context, supports skill-style instructions · open source · see Jules' talk today!
▶
Gemini CLI — has its own skill/conductor pattern · Google · see Connie's talk today!

The underlying idea is tool-agnostic: encode domain expertise into structured documents that agents consume at runtime. No code required — just well-written instructions.

22

Takeaways

Style is language, not instruction

Write in the register you want. The model mirrors your language, not your metadata.

Constraints produce better art

Content safety rules forced creative solutions. Word limits demanded precision. Both improved output.

Skills encode taste

Domain knowledge distilled into a document outperforms generic prompting every time.

Plugins distribute expertise

Open-source your aesthetic judgment. Let others invoke what took you months to learn.
