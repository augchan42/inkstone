Thesis

What Is Taste?

Taste is pattern recognition earned through iteration against good references. You can't define it upfront. It emerges through cycles of judgment.

The challenge: how do you teach something you can only recognize — never fully articulate — to a machine?

The Iterative Loop

Human Judges Output
"Like this, not that"
→
AI Extracts & Encodes Rules
Figures out why, updates the skill

Re-run. Judge again. Repeat.

The pipeline is a black box. You can't reason about the model — you can only judge its output.

Round 1: Style as Suffix

"…overflowing well, water branching… Ink wash with soft watercolor tints."

Flat. Lifeless. The model treated "ink wash" as a filter, not a language.

Round 2: Try a Different Style?

"…overflowing well… Wabi-sabi aesthetic, muted tones."

Not even an ink painting. It's a photograph. The style suffix changed the medium entirely.

Core Discovery

Style Is Not a Suffix

The prompt must read like the caption under an ink painting — painterly metaphors woven throughout, not appended at the end.

# Bad — style as suffix "A tree on a hill. Chinese ink painting style." # Good — painterly language embedded in the scene "A gnarled pine leans from a cliff face like a brushstroke frozen mid-sweep, roots gripping stone above a gorge filled with morning mist. Chinese ink painting."

The Breakthrough Prompt

Write it like the caption under the painting — not a scene plus a style suffix.

Same verse. Three layers, painterly language throughout:

  • Foreground — well mouth brims over, water sheeting across worn stone
  • Midground — streams diverge over sun-baked ground, carving shallow channels
  • Beyond — desolate hills roll to a hazy horizon, amber glints on the streams

All 7 composition rules — woven in, not listed at the end.

What the AI Analyzed

The human said “this works.” The AI figured out why.

Language register controls medium

Painterly words produce paintings. Descriptive words produce photographs.

Spatial structure creates depth

Foreground/midground/background forces the model to compose, not just fill.

Warm accents anchor attention

A single point of color in monochrome gives the eye a destination.

Framing prevents floating subjects

Gates, tree canopies, gorge walls — context creates composition.

All four principles visible

Abstract Verses? The Skill Handles It.

31% of verses have no concrete imagery. Here's how the skill turns abstract fortune into a painting:

Verse (input)

元吉无咎，安寧不殆

比 → 明夷 · "Great fortune, no blame. Peace without peril."

key 8-36 · ink-landscape · 52 words

What the skill tells the agent

# Style table fallback for abstract verses: If abstract, choose by tone: ominous → atmospheric-night auspicious → ink-landscape mixed → bold-action # Composition rules still apply: 1. Frame the scene — gates, gorges, walls 2. Force depth — foreground/mid/background 4. Warm accent — amber, vermillion, gold

Agent output

Tone: serene, auspicious → ink-landscape
Frame: valley at sunset, stone steps through a temple gate
Depth: worn steps (fg) → wanderer on path (mid) → hazy peaks (bg)
Accent: golden-hour light on the gate

The rules forced the agent to invent concrete visual elements — even when the verse gave it nothing to paint.

What Is a Skill?

A SKILL.md file with YAML frontmatter + instructions. No runtime code — pure prompt engineering that encodes domain expertise.

--- name: verse-to-prompt description: Convert classical Chinese verse into image prompts user-invocable: true argument-hint: [paste your verse here] --- # Verse → Image Prompt Given a verse, produce: 1. A style classification with rationale 2. A 50-60 word English prompt ending "Chinese ink painting." 3. A faithful English translation ## The 7 Composition Rules (MANDATORY) ...

A skill carries pre-tested expertise. The agent doesn't rediscover — it inherits.

Plugins vs Skills

Plugin = Package

  • ■ A Git repository with a manifest
  • ■ Contains 1+ skills, agents, hooks
  • ■ Installed via /plugin install
  • ■ Versioned, shareable, discoverable
.claude-plugin/ plugin.json # manifest skills/ verse-to-prompt/SKILL.md blakean-scene/SKILL.md ...

Skill = Behavior

  • ■ A single SKILL.md file
  • ■ Defines one specific capability
  • ■ Invoked via /skill-name
  • ■ No code — instructions only
# Usage: /verse-to-prompt 白駒食場，一躍而去。 Style: ink-landscape Prompt: A white colt grazes in a walled courtyard...

Takeaways

Taste is iterative, not declarative

You can't define good output upfront. It emerges through cycles of human judgment and AI analysis.

Show, don't tell

Examples teach more than abstract rules.

Human judges, AI explains

Humans select what works. AI identifies why. Humans then decide which "whys" to encode as rules.

Skills encode the loop's output

A skill is distilled taste — the final artifact of an iterative collaboration between human and AI.
