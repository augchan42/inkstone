## Findings

### [high] Constrain the OpenCode reviewer to review artifacts

**Where:** `skills/codex-review/reviewer-backends.md:85–92`
**Lanes:** security, correctness

The new command relies on `--agent plan` to prevent changes, but that agent name
does not establish a read-only boundary. OpenCode documents that Plan leaves shell
commands governed by existing permission settings, and top-level permissions can
override its edit restrictions. `--pure` disables external plugins; it does not
establish the missing permissions. The reviewer can therefore modify the reviewed
source through shell commands or inherited edit permissions. The same command
pattern is introduced in `skills/plan-review-loop/SKILL.md:102`.

Allow the reviewer to write its designated findings artifact while protecting the
implementation being reviewed. Use a scoped writable output location and suitable
permissions or isolation for source files, including shell writes and delegation.
Do not impose blanket read-only execution: the owner explicitly wants reviewers
to write their findings. Update the command and its read-only claims consistently.

Evidence: [OpenCode's Plan agent documentation](https://opencode.ai/docs/agents/#use-plan).

### [medium] Reconcile Codex's read-only mode with plan-review artifact ownership

**Where:** `skills/plan-review-loop/SKILL.md:72–75`
**Lanes:** contracts, correctness

The newly required shared backend mechanics specify `codex --sandbox read-only exec`
at `reviewer-backends.md:42–46`. The plan-review consumer still tells Codex to write
`reviews/plan-review-<id>.md` at line 83, and line 101 treats an exit without that
file as backend failure. A successful read-only reviewer cannot meet that contract,
so its review is discarded in favor of an unnecessary fallback.

Permit Codex to write its designated review artifact and align its launch settings,
prompt and completion check with that responsibility. Apply the same artifact-writing
contract to OpenCode. The owner's clarified requirement is that reviewers write
their own findings; moving all artifact writes to the orchestrator would not meet it.
